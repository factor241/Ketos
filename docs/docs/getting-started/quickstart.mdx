---
title: Build and run a flow
slug: /getting-started/quickstart
---

1. Start Ketos and open the visual editor.
2. Create a project and a flow.
3. Add compatible input, model, and output components.
4. Connect component ports and save the flow.
5. Test the flow in the playground.
6. Copy the flow ID and use the authenticated run endpoint.

Saved flow JSON and persisted component class names are runtime contracts. Do
not edit component identifiers by hand.
