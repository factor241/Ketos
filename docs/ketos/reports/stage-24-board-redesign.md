## 1. Итог этапа

Доска перестроена по трём согласованным требованиям: док перенесён вниз по центру и живёт как Dock macOS; полноэкранный режим доски удалён, «Во весь экран» уводит сессию окна в стандартный интерфейс с переносом черновика, а переключатель интерфейсов стоит на одном месте экрана; рейка окна заменена двумя независимыми панелями — левая повторяет «Рабочие папки» сайдбара, правая даёт вкладки, файлы рабочей области и просмотр. Решения А1–А7, поля раскладки, игнорируемые поля версии 1 и правки апстрим-пакетов записаны в [Agent Note этапа](../../../.agents/notes/implemented/architecture/2026-09-29-ketos-stage-24-board-redesign.md) (en/zh, парность зелёная). ## 4. Отклонения и находки

- **Регрессия `test:web` этапа 23 исправлена до Э4.3.** Гейт видимого вывода падал в шести тестах (две подписи одновременно; пропавшие строки `tooltip "…"` в aria-эталонах) из-за `Tooltip` Д2: подпись оставалась висеть, когда `setPos(null)` по `mouseleave` перезаписывался `fit()` из того же батча. Исправление в `ui-primitives`: подпись только у подключённого и видимого якоря, закрытие при потере видимости, одна подпись за раз, скрытие побеждает очередь `fit`. Aria-эталоны обновлены удалением только строк подписи. Запись — в [upstream-sync.md](../upstream-sync.md).
- **`it.fails` по Т3.* отсутствовали.** Утверждения Т3.1/Т3.2/Т3.5 были обычными `it` с Э4.1/Э4.2; в файле оставались только `it.fails` П-28/П-31 (долг этапа 23, задача `ketos-3fn.27`). Э4.6 добавил три новые проверки панелей; снимать было нечего.
- **Полный `test:web` после Э4.6 не прогонялся повторно.** Изменение Э4.6 — только файл e2e и атрибут `data-board-panel-window`; проверено целевым прогоном `board-geometry.e2e.ts` (32 passed, 2 expected fail) на сборке того же дерева, а полный `DSH_SNAPSHOT=replay pnpm run test:web` прогнан в Э5.1 (391 passed, 2 expected fail, 15 skipped) — тем же артефактом.
- **Перегенерация каталога клиента.** `slot-catalog.ts` устарел после изменений инъектируемого лица Э4.4; каталог перегенерирован и вошёл в коммит Э4.5.
- **Пара README `ui-board` и пара Agent Note перезаписаны** (`verify-translation-pairing --write`) после правок en/zh; китайская заметка ссылается на `README.zh.md` (требование локали ссылок пары).
- **А7 остаётся долгом.** Сессионная область слотов `ui-renderer` и многоэкземплярная правая панель — задача `ketos-3fn.26`; замена собственных панелей доски общими компонентами без неё невозможна.
- **GIF записан на существующем профиле стенда** (исключение провенанса по правилам skill): сервер поднят из дерева этапа, ключ — через обычный `.env`, модель ответила реальным раундом («готово», 13.6K токенов, 4 с).
