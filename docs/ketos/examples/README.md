# Ketos: примеры для приёмки MVP

Каталог содержит рабочие папки, на которых исполняется E2E-сценарий MVP ([`../mvp-e2e.md`](../mvp-e2e.md)); в нём нет кода и он не участвует в сборке.

- `ketos-mvp/` — проект для части B сценария: клон-юрист регистрирует эту папку как рабочую директорию проекта, а агент читает из неё файл-пример.
- `ketos-mvp/contracts/dogovor-postavki-2026-08-14.md` — файл-пример: договор поставки с намеренно односторонними условиями (неустойка покупателя без предела, аванс 100 %, автопродление, односторонний отказ только у покупателя), чтобы список рисков в отчёте клона был содержательным.

Сценарий использует копию папки: агент работает в зарегистрированной рабочей директории и не должен менять файлы репозитория.
