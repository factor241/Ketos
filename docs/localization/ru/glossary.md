# Глоссарий русской локализации Langflow

Этот файл является нормативным источником терминов для frontend UI, backend presentation metadata, встроенного контента и native error messages. Если контекст требует другого перевода, сначала добавляется отдельная строка с точным контекстом и письменным review; локальная импровизация запрещена.

## Контекстные различия

- `Flow` всегда означает исполняемый сценарий. `flow` в transport, route, JSON field или code identifier не переводится.
- `Run` как существительное — «Запуск», как действие — «Запустить». Stable status/event `running` остаётся `running`.
- `Build` как процесс/результат — «Сборка», как кнопка — «Собрать». CLI command и payload field `build` неизменны.
- `Authentication` отвечает на вопрос «кто пользователь», `Authorization` — «что ему разрешено».
- `Cancel` в форме — «Отмена»; `Close` для dismiss/крестика — «Закрыть»; `Abort` долгой операции — «Прервать».
- `Remove` используется, когда объект сохраняется, но исключается из связи/списка; `Delete` — когда объект уничтожается.
- Brand-containing prose переводится целиком, а защищённое имя внутри предложения сохраняется: «Подключитесь к GitHub», «Настройте OpenSearch».
- Пользовательские flow names, labels, prompts, file names и note text не проходят через glossary и показываются verbatim.

## Защищённые имена и tokens

Без перевода и изменения регистра сохраняются:

- `Langflow`, `Langflow Assistant`;
- `API`, `MCP`, `LLM`, `JSON`, `NDJSON`, `YAML`, `CSV`, `SQL`, `SSE`, `WebSocket`, `UUID`, `OAuth`, `URL`, `TLS`, `OpenAI`;
- `GitHub`, `Discord`, `OpenSearch`, `Chroma Cloud`, `Chroma Local`, `Astra DB`, `MongoDB Atlas`, `Postgres`, `pgvector`;
- provider/model/client names, включая `Claude`, `Claude Code`, `Cursor`, `Windsurf`, `watsonx Orchestrate`, `Bob (IBM)`;
- platform/language names `Python`, `JavaScript`, `cURL`, `macOS`, `Linux`, `Windows`, `WSL`;
- route paths, environment variables, API fields, event/status/type values, option values, component/input/output names, model IDs и file extensions;
- command/code literals, credential prefixes, URLs и примеры machine-format values (`login`, `openid`, `AIza...`, `sk-...`, `us-east-1`, `vector_field`).

Защищённый token не делает всё предложение непереводимым. Точное исключение для hardcoded scan оформляется только как `path + value + reason + owner + review_date`.

## Имена языков

В selector показываются native self-names и не переводятся на язык интерфейса: `English`, `Français`, `Español`, `Deutsch`, `Português`, `日本語`, `中文`, `Русский`. Код, Intl locale и display label являются разными полями registry.

## Изменение глоссария

Изменение утверждённого термина требует:

1. точного контекста и списка затронутых keys/surfaces;
2. проверки frontend и backend каталогов;
3. записи `CHANGES_REQUESTED` или `APPROVED` в `linguistic-review.md`;
4. нового visual review для строк, длина которых существенно изменилась.
