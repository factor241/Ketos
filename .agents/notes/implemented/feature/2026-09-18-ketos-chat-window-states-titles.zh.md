# Agent Note：看板窗口状态、命名与 composer 收件

Status: implemented

[English](2026-09-18-ketos-chat-window-states-titles.md) | 中文

## 问题

阶段 4 为每个看板窗口接上了真实的 Harness 会话与完整 composer，但围绕它的状态仍未完成。车道只渲染已落定的正文与单行工具名：运行中的调用不可见，结果所属调用落在已加载窗口之外时只显示原始 id，回合失败、被拒的发送与受阻的 composer 要么以服务器原文出现，要么完全没有。车道无条件跟随尾部，因此前插更早的回合会移动读者的位置。窗口标题冻结在打开时的语言环境，也从不跟随窗口重新绑定的聊天；重命名入口并不存在。composer 提供没有上限的图片、完全不支持非图片文件、没有拖放与粘贴收件，带参数的命令行会作为普通提示发出，因此 `goal`、`plan`、`feedback` 与 `permission` 从不执行。最后，活动窗口的缩放手柄环以 6–14 屏幕像素的条带跨在外框边界上：画布缩小时标题栏比条带还薄，于是手柄环盖住标题栏控件，使其无法点击。

## 决定

**所有参与渲染的窗口事实都由同一个 channel 承载。** `BoardSessionBridge` 继续为每个窗口重新发布一个身份稳定的 channel；它现在承载聊天标题（`SessionSummary.displayTitle`）、历史标志（`hasMore`、`loadingOlder`）、运行中的调用（`ChatSnapshot.legacy.runningCalls`）、图片上限（`imageLimits` 投影），以及与创建失败分开的回合失败与发送失败（`lastAgentError`、`promptError`）。外框与 body 通过 keyed 的 `useWindowSession(windowId)` hook 读取它；组件自身不订阅任何 observable。

**窗口按三级阶梯命名。** `window/window-title.ts` 依次取用户自己的窗口名（`customTitle`）、随会话而来的聊天标题，最后是该窗口类型经本地化的模板名。状态保存窗口的序号而非渲染后的字符串，因此回退名在渲染时重新解析，并跟随语言环境切换，而不是保留窗口打开时的语言环境（`ketos-1lx`）。标题栏中的名字是一个按钮，可就地编辑 `customTitle`；双击 dock 行编辑同一个值。清空该字段会移除覆盖，聊天标题随即返回。聊天面板的重新绑定路径无需改动：标题随 channel 到达。

**车道为每个状态渲染自己的本地化行，工具行由一个组件承载。** `window/ToolRow.tsx` 接收名字、失败标志、运行标志、不可用标志与重试回调；由车道决定存在哪些行。运行中的调用从 `legacy.runningCalls` 渲染并带标记；`call` 为 `null` 的已落定结果（调用落在已加载事件窗口之外）渲染为不可用，并提供重试控件再次请求更早的回合。空、创建中、创建失败、回合失败、发送被拒与运行各自有一行词典文案与稳定的 `data-board-lane-state`；受阻状态渲染在 composer 中（`data-board-blocked`），因为阻塞正是在那里起作用。加载更早回合会在请求前记录车道滚动高度与其首行，并且只在首行变化后重新锚定：落在读者下方的流式片段或运行中调用都无法吞掉锚点，重试控件也只在仍有更早页时出现。只有读者位于距底部 24px 以内时才跟随尾部，而「跳到最新」控件是绝对定位的浮层，不会改变车道高度（不会闪烁）。

**composer 执行宿主的上限，并通过宿主的上传缝暂存文件。** 图片收件与主 composer 对齐：投影出的 `imageLimits` 决定数量、单张大小与总大小，会破坏任一上限的批次整体被拒，并给出本地化原因。非图片文件经 `ctx.fileUpload` 暂存；桥把字节包成 `Blob`，使上传走后台上传载体而不是 Remote 回退路径，提示或命令随行携带暂存的回执。选择、拖放与粘贴共用同一条收件路径。以会话命令目录中的命令开头的行，会带着参数与草稿附件通过 `remote.commands.execute` 执行；不接受附件的命令由宿主拒绝，composer 在本地化标签之后显示宿主原文。命令列表在宿主注册表之外补上属于看板的 `/file`（文件选择器）与 `/model`（模型菜单）条目。Escape 只对当前草稿关闭命令面板，不会关闭聊天面板，也不清空草稿；按键落在命令面板行上时同样如此——该处理器会自行阻止事件继续传播，否则看板的 Escape 阶梯会在面板仍打开时关闭其后的聊天面板。拖放提示与文件选择器与发送遵守同一道受阻/就绪闸门，因此受阻的 composer 绝不会承诺它随后会丢弃的收件。

**提交策略在此决定，而非继承。** 裸 Enter 排队（空闲时发送），Cmd/Ctrl+Enter 引导。`ui-conversation` 的 `busyEnter` 偏好位于该插件的设置命名空间、由该插件注册，且只映射裸 Enter 手势；读取它会让看板为了一个手势耦合到兄弟功能插件的设置，而且加速手势那一半仍由看板自己拥有。看板保留自己文档化的策略，README 也如此说明。

**缩放手柄环落在窗口外框之外。** `window/HandleRing.tsx` 现在把 6px 条带与 14px 角块放在窗口盒之外，而不是跨在边界上。手柄环是屏幕空间的，其厚度无法随画布缩放；当窗口缩小到一定程度，向内延伸的条带会盖住标题栏。放在外面后，条带仍提供同样位于浮层之上的抓取目标，且绝不吞掉控件。外框自带的八个手柄保留半内嵌几何。

**composer 不再保留没有使用者的目录回调。** `pickWorkspace` 会在选中的目录中重建空白会话，但自阶段 4 工作目录芯片离开 composer 后就没有调用者；面板改为通过 `createWorkspace` 注册项目，因此删除该死回调及其桥方法。这是清理而非推翻决定：窗口通过加入项目或在项目中新建聊天来采用目录。

**工具窗口保留共享外框，不发明控件。** `WindowFrameFeatures` 仍是扩展缝（`panel`、`fullscreen`），但 `connectors`、`settings`、`dashboard` 与 `tasks` 在拥有其行为的阶段到来前不渲染额外控件；背后没有行为的刷新或设置图标只是装饰性 chrome。`AgentCard` 仍是唯一携带特性的包装，因此外框实现仍然只有一份。

## 备选方案

- **读取 `ui-conversation` 的 busy-enter 设置。** 拒绝：该设置只是看板并不共享的策略中的一个手势，而在运行时伸手进入另一个功能插件的设置命名空间正是导出纪律禁止的跨插件耦合；决定与理由记录在 README 限制中。
- **为 `@` 提及使用编辑器芯片。** 本阶段拒绝：芯片属于对话包的编辑器（看板未挂载的基于 CodeMirror 的输入）；看板插入纯文本且从不破坏草稿的换行，限制条目已说明这一点。
- **把命令执行放在 `session.command(line)` 上。** 拒绝：它丢弃执行结果，composer 便无法显示拒绝或未知命令；`remote.commands.execute` 返回失败行所需的结果。
- **提供重新运行工具的重试。** 拒绝：Harness 没有客户端工具重试；诚实的重试是再次请求更早的回合，这正是能恢复缺失调用元数据的做法。
- **保留半内嵌的手柄环并在低缩放下隐藏它。** 拒绝：隐藏恰好在窗口最小时失去缩放可达性；把条带移到外面同时保住控件与手柄。
- **加一个 data 属性而不动几何。** 拒绝：该发现是缩放 0.2 时的真实交互缺陷（审计中的 `56-rename-clickable-at-min-zoom`），不是自动化问题。
- **把 ui-conversation 的 composer 挂载进窗口。** 拒绝：看板 composer 是拥有自身草稿状态与容器查询布局的独立组件；共享编辑器需要一个对话包并未定义的槽位。

## 后果

每个车道与 composer 状态都可观察且本地化，标题栏与 dock 在任何重新绑定或重命名后都跟随聊天，composer 可以携带文件并运行带参数的命令。看板现在注入 `fileUpload`，因此组合看板的 profile 必须组合上传服务；web 捆绑包已经如此。回执是会话级宿主内存，芯片只保留名字与重试，因此上传失败在宿主重启后无法继续，窗口关闭后回执也不能再次发送。`@` 提及仍是纯文本。工具窗口在拥有它们的阶段补上模板前仍只能从测试打开。代价是：手柄环向外延伸的条带占据外框之外的少量面板空间（贴住看板边缘的窗口会失去手柄最外侧的几个像素），并且重命名通过名字本身或双击 dock 进行，而不是专门的入口。

验证：`tests/conversation-body.client.spec.tsx`（每个车道状态、运行中的调用、带重试的不可用结果、尾部跟随与前插锚定）、`tests/composer.client.spec.tsx`（受阻标签、完全访问门、图片上限、文件暂存与重试、拖放与粘贴、带参数的命令执行、看板自有的 `/file` 与 `/model`、Escape、提及类型）、`tests/window-title.client.spec.tsx`（绑定与重命名时的聊天标题、用户覆盖与清空、标题栏与 dock 重命名、回退名的语言环境重解析）、`tests/session-bridge.client.spec.ts`（标题、历史标志、失败、命令结果、上传暂存）、`tests/slots.client.spec.tsx`（路由、关闭、工具窗口无额外控件、手柄环在外框之外），以及实时审计 `.playwright-mcp/stage-06-gif/audit.mjs`（21 项检查，ru-RU 与 en-US 均 `ok: true`）。
