# @ketos/client-locale-ru

[English](README.md) | 中文

## 概述

Кетос выводит русский язык как язык интерфейса по умолчанию для русских развёртываний, не переименовывая locale-механику и не перетирая явный выбор пользователя. Клиентский плагин регистрирует `ru` в общем каталоге (фолбэк `en`), переводит `common` и `settings.locale` и выполняет переключение активной локали на `ru` ровно один раз — когда durable-раздел `locale` не содержит `preference` и браузер сам называет язык с тегом `ru` (тот же упорядоченный матч `navigator.languages`, что применяет `dsh-client-locale`). Браузеры, называющие штатные цепочки `zh`/`en` или незарегистрированный язык, сохраняют обычный браузерный фолбэк; сохранённый выбор (например `en`) принимается scope-подпиской самого locale-сервиса и не перезаписывается.

<a id="use-this-package"></a>
## 使用本包

**Runtime invariant:** 无已发布的 companion。本包通过 locale 服务注册（`addLanguage`、词典注册）和一个 settings-scope 观察器；disposal 移除语言与词典，这在 locale 目录上可观察。

`ketos` CLI 的 web 配置通过客户端插件名册加载本包，不需要任何配置；激活顺序让插件位于 `locale` 行之后，因此语言服务与其 scope 在插件运行时已经就位。已注册的特性照常通过共享查找读取俄语文案：各特性命名空间经共享链解析，`common` 现在携带全部翻译键，包括 `brand.localBuild` 的 `Локальная сборка Кетос`。插件在本地镜像 locale 命名空间与偏好字段常量（对 locale 包只做类型导入），以保持客户端打包纯净。

<a id="model-experience"></a>
## 模型体验

无模型体验：本语言包只做客户端 UI，不注册任何工具、提示词段落或会话事件，其文案从不进入模型请求。

#### KV Cache 效果

无效果；`ru` 默认值在启动时写入的那一条设置项（浏览器请求俄语且未存偏好时的 `locale: { preference: ru }`）是宿主侧持久状态，而已有 UI 显示的俄语文案经 `common` 词典到达，各特性局部词典仍回退到 `en`。

## 已知限制与暂缓事项

<a id="known-limitations-and-deferred-work"></a>

- 词典目前覆盖 `common` 与 `settings.locale`；其余客户端特性的命名空间词典经 `ru → en` 退化链解析，这些界面保持英文文案，直到各自拥有者开设 per-feature 的 `ru` 词典。
- 当浏览器请求俄语且已保存文档最初没有偏好时，`ru` 默认值通过常规写路径写入 `locale: { preference: ru }`；全新 home 因此在首次使用后记录该选择，而以 `en` 命名的浏览器保持英文。
