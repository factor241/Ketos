## 2. Находки по пути

- **Регрессия `test:web` из этапа 23 найдена и исправлена здесь.** Гейт видимого вывода `DSH_SNAPSHOT=replay pnpm run test:web` на базе этапа 23 падал в шести тестах: одновременно видимые две подписи (`getByRole('tooltip')` = 2, лишняя «Search») в `chat-scroll-contract` и `chat-long-interactions`, а также пропавшие строки `tooltip "…"` в aria-эталонах `message-actions`, `goal-multi-turn-actions`, `queue-actions`, `turn-tail-actions`. Причина — `Tooltip` из Д2 этапа 23: подпись всегда рендерится порталом, а `setPos(null)` по `mouseleave` мог быть перезаписан `fit()` из того же батча (сигнал прокрутки), поэтому подпись оставалась висеть без единого события и не закрывалась. Исправление в `ui-primitives`: подпись показывается только у подключённого и видимого якоря, закрывается при потере видимости, открытие новой подписи закрывает предыдущую, а скрытие всегда побеждает поставленный в очередь `fit`. Aria-эталоны обновлены удалением только строк `tooltip "…"` (портал выносит подпись за пределы захватываемой области). Запись — в [upstream-sync.md](../upstream-sync.md).
