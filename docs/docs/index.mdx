Ketos is a visual builder and local runtime for AI workflows. The supported
source install, configuration, API, and extension contracts are documented
here. This site deliberately excludes upstream history, promotional material,
community claims, and deployment targets not verified by this repository.

## Start locally

```bash
make init
make run_cli
```

Open `http://127.0.0.1:7860`.
