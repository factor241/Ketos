# Ketos MVP: сводный чек-лист приёмки

Сводный чек-лист собирает этапы 0–22 в одну таблицу и отвечает на вопрос «зелёный ли MVP»; его источники — отчёты `docs/ketos/reports/stage-*.md` (критерии §3) и эпики Beads `ketos-5v2.1`…`ketos-5v2.23`, чьи критерии лежат в `--acceptance` (статус эпика читается командой `bd show <id>`). Статус читается так: `закрыт` — критерии отчёта зелёные и эпик закрыт; `закрыт (ограничение)` — этап принят с записанным ограничением, ссылка стоит рядом; `закрыт (отклонение)` — критерии зелёные, но отчёт фиксирует отклонение проверки, которое предстоит закрыть; `не закрыт` — этап не закрыт. Переход этапов регулирует правило мастер-плана (вне репозитория): исключение из зелёного статуса — только Known Limitation, записанная в итоговой Agent Note MVP.
